Product walkthrough

Built around the moment finance work actually happens.

Tap a transaction to inspect policy context. Approve requests without leaving the queue. Use the receipt action to simulate capture and auto-match. Every interaction updates state immediately.

Architecture

Native-first, testable, deliberately boring where it should be.

The app keeps views declarative, isolates asynchronous work in services, and exposes deterministic state through observable view models.

Swift + SwiftUI

The browser is only the demo surface. The product is native.

The iOS implementation uses NavigationStack, Swift Charts, async/await networking, protocol-based dependency injection, @Observable view models, Codable models, and XCTest coverage for loading and approval flows.

  func refresh() async {
    state = .loading
    do {

      state = .loaded
    } catch {
      state = .failed(error.localizedDescription)
    }
  }
