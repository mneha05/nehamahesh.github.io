Memory math

What this models. Each token stores a key and a value for every layer and KV head. Physical blocks are allocated in fixed-sized token pages for each request. Allocation slack is counted, but this model does not measure GPU execution speed, kernel overhead, model weights, allocator metadata, or prefix sharing. The block diagram shows a small illustrative subset, not every page in VRAM. Calculations use binary MiB/GiB units.
